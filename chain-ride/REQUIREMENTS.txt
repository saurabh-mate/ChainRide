================================================================================
                    ChainRide — Software & Dependency Requirements
================================================================================

This document lists all software, tools, and packages required to run the
ChainRide project locally.

================================================================================
SYSTEM REQUIREMENTS
================================================================================

• Node.js          — v18.x LTS or v20.x LTS (recommended)
• npm              — v9.x or v10.x (comes with Node.js)
• Git              — v2.x (for version control)
• MongoDB          — v6.x or v7.x (local or Atlas cloud database)
• Google Chrome    — Latest version (for development testing)

================================================================================
ENVIRONMENT VARIABLES (.env files)
================================================================================

Each module (backend, blockchain) requires a .env file.

----- backend/.env -----
PORT=5000
MONGO_URI=mongodb://localhost:27017/chainride
JWT_SECRET=your_super_secret_jwt_key_here
GOOGLE_MAPS_API_KEY=your_google_maps_api_key_here

----- blockchain/.env -----
SEPOLIA_RPC_URL=https://sepolia.infura.io/v3/your_infura_key
PRIVATE_KEY=your_wallet_private_key_here
ETHERSCAN_API_KEY=your_etherscan_api_key_here

================================================================================
QUICK START — Running the Full Stack
================================================================================

1. Install Node.js (v18+), npm, and MongoDB locally.

2. Clone the project and open in terminal.

3. Start MongoDB:
     mongod
   (or use MongoDB Atlas connection string in .env)

4. Set up backend:
     cd backend
     cp .env.example .env    # Fill in your credentials
     npm install
     node server.js
   Backend will start at http://localhost:5000

5. Set up frontend (new terminal):
     cd frontend
     cp .env.example .env    # Add your VITE_GOOGLE_MAPS_API_KEY
     npm install
     npm run dev
   Frontend will start at http://localhost:5173

6. (Optional) Set up blockchain:
     cd blockchain
     cp .env.example .env    # Fill in RPC URL and private key
     npm install
     npx hardhat compile
     npx hardhat node        # Start local node on http://localhost:8545

================================================================================
ADDITIONAL NOTES
================================================================================

Google Maps API Key
  — Required for: route calculation, distance/duration, fare estimation,
    map display, address autocomplete, geolocation.
  — Get a key at: https://console.cloud.google.com/apis/credentials
  — Enable these APIs in Google Cloud Console:
      • Maps JavaScript API
      • Directions API
      • Geocoding API
      • Places API

MongoDB Atlas (Cloud alternative)
  — If using Atlas instead of local MongoDB, set:
      MONGO_URI=mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/peerride

Socket.IO
  — Used for real-time features: driver location updates, ride status
    changes, surge pricing notifications, live tracking.
